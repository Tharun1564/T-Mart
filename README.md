# TMart

A modern e-commerce landing page and shopping experience built with plain HTML, CSS, and JavaScript.

## Deploy to GitHub Pages

1. Create a new repository on GitHub.
2. Push the project to the repository's main branch.
3. In the repository settings, enable GitHub Pages and select the GitHub Actions option.
4. The deployment workflow will publish the site automatically.

## Local preview

Open the project directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000/
